免費雲端相簿

雲端空間滿了，就自己做一個。兩個檔案，照片都留在你自己的電腦，不會上傳到任何地方。

為什麼另外做小程式，不直接請 AI？依拍攝日期歸檔、找出重複照片，答案是確定的，不需要 AI 判斷。交給小程式又快又不花 token，AI 留給需要判斷的事，例如幫照片下標籤。

照片瀏覽器 .html

用 Chrome 或 Edge 打開，選照片資料夾，拖一拖就能分類、加標籤。

下載 照片瀏覽器.html

66 KB｜Windows、Mac 都能用

FileDir .command

點兩下開始：依拍攝日期整理照片，或找出重複的照片。

下載 FileDir.command

22 KB｜只有 Mac 能用。單獨下載的 .command 可能沒有執行權限，建議用下面的打包版

想一次拿齊？

兩個檔案打包在一起，解壓縮後 FileDir 可以直接點兩下。

Windows 用戶

FileDir.command 只有 Mac 能用，Windows 有兩個選擇：

  • 用原作者 AlexHsu 做的 FileDir（Windows 版，依拍攝日期自動分資料夾），下載方式看 安迪連的介紹文。我的 Mac 版就是從它得到靈感
  • 直接請 AI 幫忙分類：把照片資料夾交給它，說你想怎麼分

照片瀏覽器.html 在 Windows 用 Chrome 或 Edge 就能開，照常使用。

怎麼用

  1. 兩個檔案放進要整理的照片資料夾
  2. 點兩下 FileDir.command 整理照片
  3. 用 Chrome 或 Edge 打開 照片瀏覽器.html，選照片資料夾

第一次打開如果 Mac 跳出警告，對檔案按右鍵，選「打開」就可以。
